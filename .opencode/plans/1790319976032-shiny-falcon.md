# Plan: 42 Player-Bots mit AI

## Ziel
42 KI-Gegner ("Player-Bots") für mehr Spielspaß. Ein Match bleibt 1 vs 1 (Performance), aber es gibt 42 unterschiedliche Bots statt 4 Archetypen im Kreis.

## Warum nicht 42 gleichzeitig in einer Arena
- `index.html` ist Single-File, Kampf ist `O(N²)`: `Ent.nearestEnemy/moveBy/mostInjuredAlly` scannt pro Unit alle Units (`index.html` ca. Zeilen 729–767). 42 Units = ~1800–5000 Checks/Frame + Partikel-/Floater-Sturm + Audio-Spam → Mobile-Jank, Tower stirbt in 1–2s (42×~50 DPS vs 2000 HP).
- Safe: <30 Ents, <25 Projs, <250 Partikel. 42 gleichzeitig = nur mit Entity-Cap, Spatial-Hash, Pooling machbar → großer Umbau, Spiel degeneriert.
- Empfehlung: **Bot-Liga mit 42 Bots** (Roster), ein Duell zur Zeit. Optional später Chaos-Modus mit max. 8–12 Units.

## Umsetzung (nur `index.html`, Single-File beibehalten)
1. **Bot-Roster (42):** Neue Konstante `BOTS[42] = {name, arch (rush/tank/control/chaos), lvlMod, aggro (0–1), deck[5]}` — generiert aus `UNIT_DB` + 4 `ARCHETYPES` (Zeilen 359–364), Namen aus `BOSS_NAMES` (Zeile 365) erweitert auf 42 (z. B. Titel + Zahl). Bot-Index = `(wave-1) % 42` statt `ARCHETYPES[(wave-1)%4]`.
2. **Match-Flow:** `startGame()` (604–639): `enemyArch/enemyDeck/enemyName` aus `BOTS[i]`; Level `clamp(wave,1,12)` + `lvlMod`; Tower-Skalierung deckeln (z. B. `eHP` max ~4500, `eDmg` max ~90 statt linear bis Welle 42). VS-Overlay zeigt Bot-Name + Archetyp + Deck-Emojis.
3. **KI-Persönlichkeit:** `updateEnemyAI()` (976–1031) → `updateBotAI(bot,dt)`: Parameter pro Bot — `aggro` (Push-Häufigkeit), `saveThresh` (Elixier-Sparen), `comboFreq`, Reaktionszeit (`_aiT`-Gate). Heiler-Filter behalten (nur bei `eInjured<85%`). `enemyCD` pro Bot weiter `cardCooldown*0.7`.
4. **Progression/Belohnung:** `showEnd()` (1232–1258): Sieg → nächster Bot, Streak-Bonus behalten; Niederlage → gleicher Bot erneut. `player.history` auf 8–10 erweitern, Liga-Fortschritt `botIndex` in Save (`saveKey pepe_arena_pro_v2`) persistieren. Menü: Liga-Liste (42 Bots, besiegt/offen) + aktuelle Bot-Karte.
5. **Balance-Kurve bis Bot 42:** E-HP/Dmg/Level abflachen (z. B. `eHP=2000*(1+0.05*w)` capped, `lvl=min(12, 1+floor(w/3))`), dafür KI-Aggro/Save-Skill steigt. Erste 5 Bots leicht (Tutorial), dann Rush→Tank→Control→Chaos-Rotation mit steigender `aggro`.
6. **Caps (Safety):** `MAX_ENTS=30` in `spawn()` (671–693): Spawn verweigern + Toast wenn voll; Partikel-Cap ~300 (älteste droppen), Floater-Cap 30. Verhindert auch künftige Spam-Regression.
